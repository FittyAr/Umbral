HSTS (Strict-Transport-Security)

Sólo se envía si el request es HTTPS. 'auto' lo activa automáticamente en deployments HTTPS (recomendado). 'never' desactiva. Cuidado con max-age: una vez activado, los browsers lo recuerdan.

Default 31536000 (1 año). 0 desactiva.
Activar SÓLO si todos los subdominios son HTTPS.
Para enviar a hstspreload.org. Requiere includeSubDomains y max-age ≥ 1 año.
