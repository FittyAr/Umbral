# Guía de Internacionalización (i18n)

Umbral cuenta con un sistema nativo de internacionalización que soporta **21 idiomas** para la interfaz pública y el panel de administración. Los catálogos de ayuda interactiva están traducidos a español, inglés y portugués; el resto de los idiomas muestra la ayuda en inglés.

## ⚙️ Cómo Funciona el Sistema

1. **Activación:** La internacionalización se activa mediante el feature flag `features.i18n.enabled`.
2. **Idioma por Defecto del Portal:** En `/admin` → pestaña **Avanzado** (o dentro de la tarjeta `i18n`), el administrador puede seleccionar el idioma predeterminado de la instancia (`features.i18n.locale`).
3. **Preferencia Individual del Visitante:**
   - La portada y el panel de administración muestran un selector de idioma interactivo.
   - La selección del usuario se guarda en la cookie `umbral_locale` (con una duración de 30 días).
   - Si no hay cookie, Umbral utiliza el idioma por defecto configurado para el portal, con fallback automático a Español (`es`).
4. **Catálogos de Ayuda Interactiva (`/api/help/<locale>.json`):**
   - Todos los modales de ayuda del panel administrativo consultan textos descriptivos en el idioma activo.
   - Estos archivos se generan de forma estática en tiempo de compilación (SSG/Prerendered) para garantizar carga instantánea.
   - **Fallback al inglés:** sólo `es`, `en` y `pt` tienen catálogo propio (`src/i18n/help/<idioma>.ts`). Para los otros 18 idiomas, `getHelpTexts` toma cada clave del inglés, y en último término del español. Antes había 18 archivos que eran copias idénticas de `en.ts` (~14.000 líneas) que nadie traducía; se borraron.

## 🤝 Traducciones y Contribución Comunitaria

Como proyecto de código abierto independiente y sin presupuesto para traductores humanos profesionales, las traducciones iniciales fueron asistidas por inteligencia artificial.

Agradecemos profundamente las correcciones y sugerencias de la comunidad. Para contribuir o mejorar cualquier texto:
1. Revisa la guía en inglés en [`src/i18n/README.md`](../../src/i18n/README.md).
2. Edita el diccionario correspondiente en `src/i18n/<idioma>.ts` o el catálogo de ayuda en `src/i18n/help/<idioma>.ts`.
3. Ejecuta `npm test` (o sólo `npm run test:i18n`) para validar la paridad de claves y abre un Pull Request en GitHub.

### Agregar un catálogo de ayuda traducido
Para un idioma que hoy usa la ayuda en inglés:
1. Creá `src/i18n/help/<idioma>.ts` exportando un objeto `Partial<HelpCatalog>` (por ejemplo `helpFr`) con las mismas claves que `src/i18n/help/en.ts`. Podés traducir de a poco: **las claves que falten caen al inglés**.
2. Registralo en `CATALOGS` de `src/i18n/help/index.ts` (import + entrada `fr: helpFr`).
3. El endpoint prerenderizado `/api/help/<idioma>.json` lo toma en el próximo build.
